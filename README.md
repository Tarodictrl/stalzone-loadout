# Моё снаряжение в Stalzone

## Публикация
1. Создай публичный репозиторий на GitHub.
2. Загрузи распакованные файлы в корень ветки `main`. Файл `index.html` должен быть в корне.
3. Открой **Settings → Pages → Build and deployment → Deploy from a branch**. Выбери **main → / (root)** и нажми **Save**.
4. После развёртывания адрес сайта появится в **Settings → Pages**.

## Правки
Открой `loadout.json` на GitHub, нажми карандаш **Edit this file**, сохрани через **Commit changes**. Изменения станут видны после развёртывания.
- `player`: твой ник; `updated`: дата в формате `ГГГГ-ММ-ДД`; `demo`: поставь `false`, когда заменишь примеры.
- `items`: список в порядке отображения. Для каждого предмета укажи `slot` и `name`. Пустой список — `[]`.
- `image` необязательно: например, `"image": "./images/helmet.webp"`. Загрузи картинку по этому пути или укажи прямую HTTPS-ссылку. При отсутствии картинки остаётся иконка.

Посетители могут смотреть сайт и исходники. Чтобы опубликованные данные менял только ты, не выдавай другим права записи в репозиторий. Не добавляй токены или закрытые данные.

Для локального просмотра запусти из папки сайта `python -m http.server 8000` и открой http://localhost:8000/. При открытии HTML двойным кликом загрузка JSON может быть заблокирована.
