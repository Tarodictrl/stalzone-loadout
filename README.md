# Экипировка STALZONE

Публичный инвентарь. Чтобы осмотреть предмет, нажми на его карточку. Закрыть осмотр можно кнопкой «Назад» или клавишей Esc.

## Изменить инвентарь

Отредактируй `loadout.json` в ветке `main` через карандаш на GitHub. Обнови `updated` в формате `ГГГГ-ММ-ДД`. Если добавляешь новый экземпляр, вставь ещё один объект в массив `items`. Названия могут повторяться, но `id` у каждого экземпляра должен быть свой. `kind` определяет раздел: `weapon`, `armor`, `container` или `other`. `slot` — необязательная подпись, например `Автоматы`. `upgrade` — числовой уровень заточки.

Минимальная запись:

```json
{
  "id": "famas-g2-2",
  "kind": "weapon",
  "slot": "Автоматы",
  "name": "FAMAS G2",
  "upgrade": 15,
  "image": "./images/famas.png"
}
```

Необязательные поля экземпляра:

- `stats`: характеристики показываются только у оружия. Пример: `[{"label":"Прочность","value":"79,3%"}]`. Значение записывается строкой.
- `attachments`: массив вида `[{"slot":"optic","name":"Название прицела"}]`. Стандартные слоты: `muzzle`, `handguard`, `tactical`, `grip`, `optic`, `charm`, `stock`, `magazine`. Дополнительные слоты можно указать под собственным названием.
- `cosmetics`: массив вида `[{"slot":"paint","name":"Название краски"}]`. Стандартные слоты: `look` (облик), `motif` (мотив), `paint` (краска); прочие названия тоже поддерживаются.
- `preview`: путь к изображению конкретного экземпляра для экрана осмотра. Без него используется `image` — обычная иконка без увеличения. Картинка сама не меняется при добавлении краски или обвесов.
- Для контейнера `artifacts`: массив вида `[{"name":"Смольник","upgrade":15,"image":"./images/smolnik.png"}]`. У каждого контейнера свой список. Проценты не отображаются.

В `attachments` и `cosmetics` у отдельной записи тоже может быть `image`. Поддерживаются относительные пути внутри сайта и прямые HTTPS-ссылки. Данные и файлы публичны; не записывай в репозиторий секреты и не выдавай права записи посетителям.

## Публикация и локальный просмотр

**Settings → Pages → Deploy from a branch → main → / (root)**. Сборка и сервер не нужны. Для локального просмотра запусти из папки сайта `python -m http.server 8000` и открой `http://localhost:8000/`; при открытии HTML с диска загрузка JSON может быть заблокирована.
